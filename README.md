# 🌟 بوت تليجرام مساعد «المتفوق» الذكي والأسطوري 🚀

مساعد ذكاء اصطناعي (AI Assistant) متكامل لمشروع «المتفوق» يستقبل النصوص، الملاحظات الصوتية بالميكروفون، روابط يوتيوب، ملفات الـ PDF، وصور السبورات والمذكرات، ويقوم بتحليلها وفصل المادة العلمية بدقة 100% وإخراج ملازم A4 بصيغة PDF مباشرة باسم الدرس مع دعم التعديل ونظام كويزات تفاعلية متطور.

---

## 💎 أحدث المميزات والإمكانيات المضافة:

1. 🧠 **نظام الكويزات الاحترافي المتكامل (أمر `/quiz`):**
   - **كويز سريع تفاعلي (Telegram Quiz Poll):** أسئلة اختيار من متعدد تفاعلية مع إظهار الإجابة الصحيحة وشرح السبب عند الحل.
   - **كويز PDF احترافي جاهز للطباعة:** توليد ملف PDF كامل خاص بالكويز بنفس هوية «المتفوق» مع دوائر اختيار ومفتاح إجابات بالأسفل.
   - **خيارات تخصيص مرنة:** اختيار نوع الأسئلة (اختيار من متعدد، صح وغلط، أكمل)، مستوى الصعوبة (سهل، متوسط، صعب تفكير عليا، متنوع)، وعدد الأسئلة (3 إلى 20 سؤال).

2. ✍️ **قسم «حِلّ بإيدك» ومساحة الإجابة:**
   - مساحة مخصصة ومخططة (`.workspace-area`) للطالب لحل المسائل بنفسه أولاً.
   - مفتاح الإجابات النموذجية (`.answer-key`) بالأسفل تماماً للتحقق بعد الحل.

3. 📑 **دعم ملازم ممتدة حتى 10 صفحات A4:**
   - دعم التوسيع وإنشاء ملازم من صفحتين وحتى 10 صفحات A4 متتابعة بدون صفحات بيضاء فارغة.
   - تباعد أسطر مريح ومسافات واضحة تمنع تكدس النصوص وتريح العين.

4. 🔄 **تدوير مفاتيح الـ API التلقائي (API Failover Pool):**
   - إمكانية إضافة عدة مفاتيح في `GEMINI_API_KEYS=key1,key2,key3`.
   - في حال انتهاء رصيد أو حد أي مفتاح، ينتقل البوت تلقائياً وفورياً للمفتاح التالي دون تأثر المستخدم.

5. 🛠️ **نظام التعديل التفاعلي وحفظ نسخة HTML احتياطية:**
   - يرسل البوت ملف الـ PDF مسمى باسم الدرس تلقائياً.
   - يحتفظ البوت بكود HTML الأخير؛ بضغطة زر `✍️ تعديل على هذا الملف` يمكن طلب أي تعديل (إضافة أسئلة، شرح نقطة، تعديل صياغة) ويعيد البوت بناء الـ PDF فوراً.

6. 🎀 **اعتماد الهوية الرسمية «الورقة الملونة» وشراكة «بوت Thanawiyah»:**
   - الهوية البصرية الرسمية المعتمدة مع إمكانية التبديل بين مختلف الهويات المتاحة عبر `/identity`.
   - شريط الشراكة الرسمي والعلامة المائية الشفافة (5%).

---

## 📱 أوامر البوت المتاحة:

- `/start` - القائمة الرئيسية ولوحة التحكم.
- `/quiz` - قائمة تصميم وإطلاق الكويزات الاحترافية.
- `/identity` - اختيار الهوية البصرية للتصميم.
- `/partner` - تفعيل أو تعطيل شريط الشراكة الرسمي.
- `/advisor` - مرشد تقييم دقة المصادر ومطابقتها للمنهج.
- `/help` - دليل الاستخدام السريع وشرح المميزات.

# Railway deployment

This Telegram bot is configured for Railway using Nixpacks. Set the variables in `.env.example` in Railway Project Variables before deploying. The service exposes `/health` on Railway’s `PORT`.

## التشغيل الآمن والفحوصات

- أصبح `REQUIRE_AUTH=true` هو الوضع الافتراضي. يجب ضبط `ALLOWED_USER_IDS` أو `ADMIN_IDS` قبل تشغيل البوت في الإنتاج.
- يتم تعقيم HTML المرسل أو المرفوع قبل تمريره إلى Chromium، وتُحظر وسوم التنفيذ والخصائص الحدثية وقواعد CSS الخطرة.
- تُحفظ جلسات المستخدمين في `SESSION_FILE` مع حفظ ذري مؤجل. على Railway يفضّل ربط المسار بـ Volume أو تخزين دائم.
- يتطلب `/health` و`/ready` اكتمال اتصال Telegram ووجود مفتاح Gemini صالح حتى يعيدا حالة الجاهزية.
- أوامر التحقق المحلية: `npm run check` و`npm run lint`.
- تم تحديث Puppeteer إلى إصدار يعالج ثغرات `extract-zip`، ويجب إعادة اختبار إخراج PDF عند تغيير إصدار Chromium.
